# Blue Back Landscaping LLC — Website

Static marketing website for **Blue Back Landscaping LLC**, a professional landscaping and property maintenance company based in West Hartford, CT.

Live site: [bluebacklandscaping.com](https://www.bluebacklandscaping.com/)

---

## Pages

| File | URL | Description |
|------|-----|-------------|
| `index.html` | `/` | Homepage — hero carousel, services overview, contact strip |
| `services.html` | `/services.html` | Full residential services listing |
| `commercial.html` | `/commercial.html` | Commercial & HOA services |
| `about.html` | `/about.html` | Company background |
| `privacy-policy.html` | `/privacy-policy.html` | Privacy Policy |
| `accessibility.html` | `/accessibility.html` | Accessibility Statement (WCAG 2.1 AA) |
| `terms.html` | `/terms.html` | Terms & Conditions |

## Tech Stack

- Plain HTML5, CSS3, vanilla JavaScript — no build step, no frameworks
- WCAG 2.1 AA accessible (skip link, ARIA landmarks, keyboard nav, focus styles)
- Responsive down to 480 px
